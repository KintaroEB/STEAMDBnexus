About this gameFull description from Steam+
In Wolfpack a crew of players man the stations of a German type VII U-boat. Their objective is to intercept and sink enemy ships and escape undetected. The game is played in an unbroken first person perspective. Players interact directly with valves, levers and instruments to control the U-boat. The U-boat in Wolfpack is fully operational and interactive. All stations and instruments have been carefully modeled after original pictures and sources, and kept as realistic as possible without compromising usability. The game allows players to: Play as one or several U-boats. Play multiplayer, or solo with bots. Use advanced plotting tools to plan attacks and to navigate. Manually operate the diesel engines and electric motors. Use dive the planes and rudders. Operate the ballast tanks, trim tanks, and air vents. Use periscopes, and the torpedo data computer. Use the hydrophone to find targets and avoid the enemy. Use the deck gun and anti aircraft gun. Use voice tubes and intercoms to communicate throughout the boat. Communicate with other u-boats over radio using real time, enigma encrypted morse code. We are currently working on the most significant update that the game has ever received. We have completely rewritten the game’s systems to enable new game modes, dedicated servers, PVP and open world gameplay. Current state of the game Today, Wolfpack is played in a single battle mode, called Skirmish. In this game mode, the players are tasked with attacking and destroying an escorted convoy of ships in an open sea battle. The game is played peer to peer, with one player hosting the game. The next big update Our next big update to the game will be a new game mode called Career mode. Career mode is an open world game mode where players can travel to any location on earth. Unlike skirmish mode, progress in career mode will be saved between sessions. The career will be divided into chapters, with each chapter covering a small portion of the war from 1939 to 1945. The first update will contain the first chapter, with more chapters added over the course of development. This update also contains manual navigation, more enemy unit types, and a versus mode. Skirmish mode will continue to exist in the game as currently implemented. Career mode world map - Work in progress Playable corvette The career mode update will also contain a versus mode, where one team plays as one or several Flower class corvettes defending a convoy, and the other plays as u-boats. The playable corvette is still in an alpha stage, with many of its systems missing. It will be available as part of the career mode release, and will be gradually improved in future patches. Playable corvette - Work in progress. Exterior, wheelhouse, Typex machine, bridge. Further development After the Career mode update we will also add: Support for player run dedicated servers. New character models. New U-boat damage model with flooding. Manual torpedo reloading. Mission editor. U-boat upgrades. New enemy ships.
