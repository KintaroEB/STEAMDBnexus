About this gameFull description from Steam+
准备好和可爱的永雏小菲们“一起”建设小镇了吗？ 在这个被无情大手所操控的奇怪世界中，不知为何会有无数个服装各异的小菲会从街边冒出来，而无情的大手会把她们抓去建设小菲镇！您将在游戏中亲自扮演无情大手，并且把您邪恶的大手伸向无辜的小菲们！ 指派工作 正如游戏的标题，在拖拖拉拉小菲镇中，您会把小菲拖来拽去，把她们丢进各种各样的工作区，给她们指派各式各样的工作。从收集薯条到研究科技点数，谁能想到看上去笨笨的小菲们其实可以从事各种各样的工作和活动？她们能完成的事情比三岁儿童更多！ 建造小镇 随着资源的累积，小镇也会不断地扩展，通过您的操作，小菲镇会从一片荒凉的空地发展成拥有各种建筑和工作机会的超级小镇！而无情的大手则可以决定哪只小菲可以成为居民，哪只小菲会被驱逐！ 物理效果 在小菲镇，小菲们被赋予了物理效果，当你把她们丢出去时，她们会做出各种各样的自然反应, 来试试你可以把她们丢多远吧！ 免责声明：物理系统可能会导致小菲发生莫名其妙的扭曲和抽搐，但我们保证没有小菲会因此受伤。 升级小镇 在游戏中不停的升级小菲镇，升级小镇就可以建造更多的建筑，从而增加小菲的就业机会，毕竟小菲的价值就是不停的工作。尝试升级到满级来把小菲镇建造成超级小镇！ 建筑 在小菲镇上，您可以解锁各种各样的建筑，这些建筑可以给小菲们提供新的工作，不仅于此，小镇上的建筑全部都可以升级！升级后的建筑会提高小菲在建筑上的生产效率，当建筑升级到满级时会发生什么呢？小菲会很好奇的…… 服装 游戏中有四种穿着不同服装的小菲，从经典的侦探菲到容易被限流的兔女郎菲，亦或者是好欺负的1883菲和可爱热血的偶像菲，无论哪种都会被无情的大手玩弄于股掌之间！穿着不同服装的小菲会随着小镇的发展逐渐出现在小菲镇中。 小镇公告：小菲独特的大脑构造可能会降低帧率，所以我们限制了入境小菲的数量。 轻松愉快 准备好各种零食！拖拖拉拉小菲镇是一款面向雏草姬的同人向游戏，享受轻松愉快的游戏节奏，把小菲们丢来丢去，不用担心游戏会失败！随心所欲的在游戏世界中闲逛，甚至放在后台都没关系！ 不过请记住随时回来查看一下您的小菲，当娱乐值耗尽时小菲可能会偷懒，甚至逃跑！
