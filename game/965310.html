About this gameFull description from Steam+
In this modernized version of The Settlers – Rise of an Empire, you can build vibrant cities in a medieval world. Each character leads their individual lives and can be observed by you at any time. The main goal of the game is to increase the wealth of your empire and to go down in history as a legendary king. Includes the main game and the expansion The Eastern Realm. IMPROVEMENT HIGHLIGHTS: Windows 10 compatible, multiplayer via Uplay
