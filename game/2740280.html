About this gameFull description from Steam+
Tactic Boxing is a boxing game with ragdoll physics, local multiplayer, career mode and manager mode. - Active Ragdoll Physics - 3 Boxing Styles: Puncher, Slugger, Out-Boxer - 9 skills (strength, accuracy, health, stamina, footwork, attack speed, chin, HP and SP recovery) - 40 boxers (not real) - In-Game Editor - Training Camp - Game Settings (damage, health, knockout chance, etc.) - Career Mode - Manager Mode - Quick Fight Mode - Player vs AI - AI vs AI - Player vs Player (Local Multiplayer) (a controller is required for local multiplayer) - Mouse and keyboard controls - Gamepad controls
