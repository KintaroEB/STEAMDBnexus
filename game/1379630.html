About this gameFull description from Steam+
In order to launch the mod make sure that Steam version of original Return to Castle Wolfenstein is installed RealRTCW is an overhaul mod for critically acclaimed Wolfenstein classic. It features improved visuals, expanded arsenal, rebalanced gunplay and proper modern systems support! Technical upgrades: Proper widescreen support (iortcw) OpenAL sound API support - better sound quality (iortcw) Steam Workshop integration Steam Achievements Steam Rich Presence Subtitles support Visual and audible improvements: HD weapon models New weapon animations HQ textures for the environment and characters Overhauled sound effects Atmospheric effects support - rain and snow New modular HUD and UI Gameplay changes(most of them optional): Expanded arsenal New enemy types New inventory items Rewards system for finding secret areas Overhauled gunplay Rebalanced AI Bonus game modes for more challenge Difficulty levels overhaul - it affects everything now Realism difficulty level Free roam interactive hub - Malta HQ Survival Mode featuring endless waves of enemies
