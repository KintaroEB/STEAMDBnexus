About this gameFull description from Steam+
★富甲Online新登場，賺錢、徵才、打寶、升級，組自己的夢幻隊伍！ 　　《富甲天下４》包含了完整的線上功能，每個玩家在富甲Online世界中，都能自創角色，暢玩賺錢升級的標準賽、打怪奪寶的挑戰賽、並且在富甲小舖中聘用人才、買賣各式裝備及道具，還有好友名單、線上聊天、線上排行榜等，透過打寶、升級等方式不斷增加實力，最後達成稱霸三國世界的最終目標！在富甲４Online等同一個完整線上遊戲，不過玩家不需要繳月費或買點卡，這些額外的服務都是完全免費的！慢慢培養出自己的夢幻隊伍，在挑戰賽中與來自各方的英雄們逐鹿天下！ ★城池建物添風貌，箭塔、兵營、私掠站，多種組合功能多變！ 　　富甲４另一項主要特色，就是以往只能在城池內才能看到的建物，不僅在功能上大幅增強，並且將直接顯示在地圖上。玩家只要到工匠屋購買想要的建築圖，就可以在自己的城池中興建最多三座的城池建物。遊戲中的城池建物高達數十種，每種建築物都有獨特的造型，使遊戲畫面將更豐富。如果玩家以為這些建物只是裝可愛那就大錯特錯囉，每種建築物都有不同的功能，而且還有影響範圍的特性，例如玩家在敵軍的勢力範圍內的某座城池中蓋個屎王神像，那麼附近所有城池的人口將急速銳減，說不定就能使得堅固的敵城不攻自破；此外像興建箭塔，只要敵人經過此處，必能萬箭齊發讓他付出慘痛的代價。而城池建物最可怕的地方，在於他的效果是可以重疊的。假如玩家在城池中同時蓋了箭塔、萬骨塚和收費站，當對手踏入城池影響範圍時，不但會身受重傷，同時造成士兵逃亡、及痛失錢財的悲慘下場，真可說是賠了夫人又折兵喔！ ★錦囊妙計轉乾坤，單挑、野戰、攻城戰，文官武將各顯神通！ 　　富甲系列中最讓人愛不釋手的戰爭系統，這次也做了新的設計，從指派武將參戰，到選定攻城及守城機關，甚至調配兵力，玩家在戰場上的一舉一動都足以扭轉戰局的演變。尤其這次在戰爭中增強了錦囊的設計，讓文官在戰爭中所扮演的角色，比以往更加吃重了。例如可以強迫對手交過路費的「扮豬吃虎」；單挑時換取敵方超強武器的「互通有無」；以及能改變野戰地形的「種木成林」；讓耐久度固若金湯城池瞬間摧毀的「孟女哭城」等等，製作小組精心設計了八十幾種錦囊妙計，讓玩家更能體驗戰場上瞬息萬變的盡張氣氛。而在武將方面，新增的吼叫技，將使張飛得以發揮「長阪橋之役」時，那種一夫當關，萬夫莫敵的豪邁真性情。而最精采的莫過於單挑場面，特殊的視角、流暢的畫面、與華麗的必殺技特效演出，玩家可能會以為自己在玩一款格鬥遊戲呢！ ★賭場鬥智拼手氣，擲骰、賽馬、下寶物，緊張刺激欲罷不能！ 　　除了建設與戰爭的創新變革之外，研發小組也沒放過遊戲中的任何一個小細節。前代原有的骰子賭場與賽馬場等小遊戲，在本作中不但玩法徹底翻新，並且配合富甲的連線功能，更強調以『互動』作為設計的主軸，只要有任何主公進入賭場，其他主公也可以一起參與賭局，讓原本單調的一人賭局變成大家同樂。例如在骰子賭場中，所有主公必須輪流擲骰子以決定點數，七添﹙加注 100兩﹚八拿﹙可得 100兩﹚九通殺﹙獨得所有賭金﹚十沒份﹙完全沒機會了﹚，緊張刺激的程度一定讓人腎上腺素暴增；而在賽馬場中，加入了獨創的寶物的設計，十數種如大力丸、寶物炸彈、豬羊變色、天外橫財等等寶物，讓主公們有機會在馬兒開跑前輪流下注，不僅可以幫助自己中意的馬兒獲勝，當然也可以陷害其他馬兒，每次下注都可能讓對手變臉、賭局變色，詭譎多變的氣氛，絕對刺激有趣喔！ ★關卡地圖新花樣，天梯、開路、熱汽球，劇本加倍絕對過癮！ 　　這次富甲４的地圖將首次加入立體高程的概念，玩家可以透過天梯、熱氣球到其他區域開疆闢土，使得主公在地圖上的移動更多變化；而開路的設計則使得大富翁遊戲呈現出完全不同的樂趣，只要玩家資金充裕，便可以開路方式另闢蹊徑，到達原本無法到達的地方，除了可以改變遊戲世界的規模，還可因此獲得一座具有收費站功能的城池，想走這條路的主公，當然就得乖乖留下買路財喔！在研發小組的巧思下，富甲４的劇本不僅增加，而且挑戰性也更高了，每個主公足足擁有十三關的劇本，玩家將有機會與勢力龐大的董卓軍、會使妖法的黃巾賊、獻帝之妹龍翠公主所率領的娘子軍、以及擁有眾多奇能異士的南蠻軍等一較高下。大富翁遊戲到底能夠做到多好玩呢？試試富甲天下４，相信玩家就能找到答案了！
