About this gameFull description from Steam+
Pixel art animation software PixelOver is a pixel art oriented animation tool designed to turn your artwork into clean, pixel-perfect renders. Use real-time effects like dithering and indexation, then animate with keyframes and bones while keeping clean results thanks to pixel-art resampling. Main features Import images, GIFs, and 3D models Layer-based workflow with pixel-art effects: indexation, dithering, pixel-perfect lines, color cycling, and more Parent-child transform system for building clean hierarchies Real-time animation with keyframes and bone rigging Inverse kinematics (IK) for faster posing and character animation Mesh deformation for flexible 2D animation and advanced rigs Export to images, GIFs, or spritesheets
