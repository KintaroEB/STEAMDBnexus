About this gameFull description from Steam+
"Deduce Together" is a cooperative and competitive online multiplayer game where players ask the AI about characters, locations, and more to uncover the correct answers. Try asking questions that can be answered with "YES" or "NO" to the given problems. Overview Private Session: Only players who know the room information can join. Enjoy the game privately with friends or acquaintances. Competitive Gameplay: Players compete against each other to achieve the highest accuracy rate. Deduction and questioning skills are key. Customizable Game Settings: Adjust the challenge level by freely setting time limits and the number of questions. Challenge your reasoning skills and aim to become the ultimate knowledge champion in dedicated sessions with friends and acquaintances! Currently, you can use the default question set and user-created question sets. default question set Character Quiz (Beginner) World Tourist Spot Quiz (Beginner) Historical Figure Quiz (Beginner) Country Quiz Movie Quiz (Beginner) Game Quiz (Beginner)
