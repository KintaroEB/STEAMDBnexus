About this gameFull description from Steam+
Stream Avatars is an interactive overlay for live broadcasters on Twitch, Facebook, Youtube, Trovo, Kick, Chzzk Naver,   Dlive, and TikTok (limited). It even works with multiple services at the same time! Your viewers can knock each other off the screen with punches, bombs, or a duel show match where the winner takes all! Unleash Your Creativity! You can create your own avatars, equipment, and name tags to fit the theme of your stream. If creativity is not your strong suit, download some community-made Avatars from the Steam workshop! Currency Integrations Mixitup, Streamlabs, & Stream Elements Disclaimers Do you use a dual PC setup? - If you do, you might need to get Stream Avatars on a secondary steam account for the streaming machine instead of your primary steam account! Family Sharing is not possible for Software on steam* Mac OSX Must use an integration in window settings called "Syphon", or use window captures with chromakeying out the background. Support / Help -If searching the documentation site doesn't help, Feel free to visit the discord for help with any issues you might be having. -Commands: After you connect, Type: !commands
