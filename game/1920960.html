About this gameFull description from Steam+
VPet is a desktop pet software(game) that supports various interactive. it is open source, free and support Steam workshops This game is independent from the built-in desktop pet (tutorial) program of VUP Simulator, if you like it, you can also add VUP Simulator to your wishlist Lots of interactions and animations More than 200 Type of Animation, Some Animation Examples: touch the head & Body bring up dance climb the wall See more image resources details in open source docs Free The game is completely free! The main purpose of the game is to promote the VUP-Simulator, This is the desktop pet inside the VUP Simulator. Open Source The game is open source on github, welcome to put forward your own ideas, ideas or participate in the development! You can also modify the code to make your own table pet! (Although most of the content supports the workshop, is no need to modify the code) project address: github-LorisYounger/VPet Support Steam Workshop The game supports the Steam Workshop, you can make animations or interactions with other characters and table pets, and upload them to the creative workshop to share with more people.
