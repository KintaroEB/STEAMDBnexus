About this gameFull description from Steam+
NOTE: Purchasing Steam DLC gives you access to full data on the Windows version of DashPanel ONLY!! If you wish to access full data on Android or iOS devices purchase the full data unlocks within the DashPanel application on the desired platform. « DashPanel » ► Data display for your favourite racing simulators. Create fully customizable dashboard displays for your favourite racing sims on your PC (USB monitors, USB480, VoCore, overlay mode on screen or SteamVR compatible HMD). ► Virtual button box for any application or game. Use virtual buttons to trigger keystrokes on your PC via attached touch screens. « Key Features » ►Data display, show critical information from your racing sim. ►Button box functionality (PC only), use virtual buttons to trigger keystrokes on your PC. ►Powerful editor allows you to modify built in dashboards or build one from the ground up. ►Easily download and share created dashboards online within the app. « Demo Data » Ensure compatibility on your devices and try the time unlimited demo version that reads RPM, Speed and Gear. Full data unlocks can be purchased for each game via the in app store tab. « Demo Button Box » Virtual Button Box has a limit of 30 button presses per session in demo mode. Owning a full data unlock for a game will give unlimited presses for compatible games. To use a button box on any application or game purchase the Virtual Button Box unlock via the in app store tab. « Supported devices » •Main monitor as an overlay on top of the game •USB Monitors that extend the desktop •VR HMD as overlay (SteamVR only) •USBD480 (touch not supported) •VoCore Screen « Games Supporting Data » • American Truck Simulator - ATS • Assetto Corsa (PC/PS4) • Assetto Corsa Competizione - ACC (PC) • Assetto Corsa EVO • Assetto Corsa Rally • Automobilista • Automobilista 2 • BeamNG.drive • DiRT 4 (PC) • DiRT Rally (PC) • DiRT Rally 2.0 (PC) • Euro Truck Simulator 2 - ETS2 • F1 2012 - 16 (PC) • F1 2017 - 25 • Farming Simulator 22/25 (PC) • Forza Horizon 4/5/6 (FH4 Note: Data Out Telemetry is not working on Xbox Series X|S - Playground Games) • Forza Motorsport 7/23 • Grand Prix 4 • GRID 2019 (PC) • Grid Autosport (PC) • GRID Legends (PC) • GT Legends • GTR2 • iRacing • KartKraft • Le Mans Ultimate • Live For Speed - LFS • Project Cars - pCars • Project Cars 2 - pCars2 • Project Cars 3 - pCars3 (PC) • Race07 • RaceRoom Racing Experience - R3E • RBR NGP6 • rFactor • rFactor 2 • WRC Generations • Wreckfest 2 (PC) indicates that telemetry is available only from the PC version of the game.
