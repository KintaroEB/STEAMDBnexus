About this gameFull description from Steam+
游戏简介 《三国群英传IV》是由奥汀科技研发的一款即时战略类游戏，是三国群英传系列的第四作。玩家将在游戏中重历三国时代，指挥武将驰骋于华夏神州大地之上，征战于天南地北之间，平定乱世，以一统中原为目标，最终建立属于自己的英雄事业。 游戏特色： 1. 内政系统即时演算，文官智力大有所用 游戏整体即时化，在内政上也进行了全面的调整。首先，在内政施行的方式上，不再受到回合的限制。再者，拥有能力强大的文官，便可以在更短的时间内完成内政的项目，相应的，也能施行更多的内政项目。 2. 野战系统中，地形因素影响战斗 游戏中的大地图力求将真实的场景更好地呈现出来，使得武将能奔驰在壮丽的山河中。所有的城池、地形、路线等都非常清楚，地图上的固定路线将不复存在，城池与城池之间存在的会是群山、江水、丛林等能够自由移动的中原大地。进攻敌国之城不再受限于固定路线，不过，玩家也要随时保持警戒，防范敌国随时伺机侵略空虚的后方。 3. 兵种阵型影响战局，弱势亦可变优势 一个军团最多将能够组成包含五个不同兵种的部队，让《三国群英传Ⅳ》的千人战在游戏性方面能够拥有更多的变化。玩家需善用阵形，将士兵安排在他能够发挥最大作用的最佳位置上。只要善用阵形，任何玩家皆能战无不胜，攻无不克。 4. 随机事件丰富多样，三国事件再体验 随着游戏中各种不同层面的即时化，各种不同的事件，也将应运而生。除了既有的三国时代大事之外，因势力、君主、情势等等的不同，各种假设的情况，在历史中可能存在的事件，也被混入事件系统之中。各种曾经被你所想象过的事件及可能性，这次，都将发生。有各种因情势不同而产生的”未知”存在于《三国群英传IV》中哦。 注：游戏暂不支持窗口模式
