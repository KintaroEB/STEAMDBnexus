About this gameFull description from Steam+
Skydimo is a professional RGB lighting control platform designed for immersive ambient lighting and multi-device synchronization. Users can synchronize lighting effects with: - Screen content (real-time screen color capture) - Music and audio rhythm visualization - Games and desktop applications - Custom lighting effects and scripts With Studio mode, users can visually design lighting layouts, assign lighting zones to different devices, and fine-tune colors, brightness, animations, and transitions. Multiple lighting profiles can be saved and switched instantly. The software runs entirely locally, providing low-latency real-time rendering, high stability, and full privacy. Supported Hardware: - Skydimo Monitor Ambient Light Strip (SK01 / SK0127 / SK0132 series) - H202-Pro / H205-Max RGB Light Bars - Skydimo USB RGB Controllers (HID / CH340 based) - WS2812 / ARGB LED strips connected via Skydimo controllers - RGB motherboards, graphics cards, memory, fans, coolers, keyboards, mice, and accessories - Compatibility with major RGB ecosystems including ASUS Aura, MSI Mystic Light, Gigabyte RGB Fusion, Corsair iCUE, Razer Chroma, Logitech G, and more For a full searchable list of supported models, please visit: System Requirements: - Windows 10 / 11 (64-bit) - Available USB port for hardware connection Additional hardware support will be continuously expanded through future updates.
