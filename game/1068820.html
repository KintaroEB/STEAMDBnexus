About this gameFull description from Steam+
Please read this section before purchasing! OVR Toolkit only supports Windows 10 and 11 OVR Toolkit requires you to have a Windows account with admin permissions and that you run Steam on this same account Standalone headset users - Read the 'Important Stuff' section before purchase! Overview OVR Toolkit is a SteamVR Overlay utility designed to make viewing the desktop within VR easy and intuitive. OVR Toolkit allows you to display specific desktop windows, quickly select between them, use intuitive controls to navigate those windows, and use a virtual keyboard to type. Ever wanted to reply to Discord messages without taking off your headset or looking through a nose piece? Ever wanted to pause that song you're listening to without fumbling around on your keyboard? Now you can with ease! OVR Toolkit is compatible with all SteamVR compatible headsets, such as all Meta headsets, Steam Frame, Valve Index, etc. (Note: Games must be running through SteamVR for OVR Toolkit to be usable, games running on the headset itself are not supported!) Features Overlays over almost all SteamVR applications: OVR Toolkit will display on top of all your favorite titles! (VRChat, Beat Saber, etc.) Desktop window viewing: Allows you to select a desktop window and display it above your hand, or pin it in the world around you. Multiple desktop windows: Create multiple different windows and place them in the world around you. Attach windows to tracked devices: You can make windows move around with either your left or right controllers, headset, or have them stationary in the world. Curved overlays: Want to improves readability of large windows in VR by wrapping them around you by a configurable amount? Now you can! (Or you can make the window into a wall by curving it to the max, I don't judge!) Window re-centering: This feature will make window's re-appear in front of you when you turn them on regardless of your position in your play space. This is useful for users who move around a lot in VR, such as standing/sitting/lying down! Intuitive desktop input: Scroll up and down on windows by dragging, make a selection by dragging, pinch with both controllers to zoom content, like using your finger on a phone but with a VR controller instead! (This makes a lot more sense than it sounds like it does!) Wristwatch: An overlay displayed on your hand that displays the time, date, device battery percentages, as well as other values such as CPU/GPU/VRAM usage. Battery time remaining estimates: Prefer to know how many hours of charge you have left instead of what percentage? OVR Toolkit will learn and adapt its knowledge of your devices with each charge cycle to better predict the remaining time, providing a 1 hour and a 30 minutes remaining warning. (Note: Requires a full charge cycle of your devices before this data is available) Saving/Loading layouts: Like that sweet setup you've made? Well, now you can save it, and load it again next time you launch! Save multiple layouts: Want different layouts for different games? Who am I to judge!? Advanced settings for window capture: Want that 60 FPS window capture experience? Want to make a window slightly transparent so it's less in the way? Want a window to disappear when you're not looking at it? Or when it's past a set distance from you? You can do these with our advanced settings! Adaptive Framerate: When enabled, performance mode will lower the capture rate of windows you are not using, this helps game performance by decreasing the resource usage of OVR Toolkit whilst still keeping your desktop smooth when you're actually using it. Media controls: Shows now playing track, album art, progress in the song, with buttons for previous, pause/play, and skip. Supports any media player that appears in the Windows now playing section. (Spotify, web browsers, Foobar, WinAMP with a plugin, VLC, etc.) Windows notifications: Display your Windows notifications in VR such as Discord messages, 'Your Phone' notifications, and anything else that would typically appear on your desktop as a push notification. Macros: Create macro keybinds which can be activated by a click on the wrist to trigger a series of key presses. (Such as changing OBS scenes, muting/un-muting Discord, etc.) Paste to Game: Clicking the Paste button found under the keyboard will automatically tab in the currently running game and push Ctrl and V. (Can be used to paste links into VRChat video players, paste join codes into codes, etc.) VRChat integration OSC parameters: Show when your windows are toggled on, your battery levels, and a bunch more. Check our wiki! Media to chatbox: Show what song you're currently listening to, with a configurable time for how long this is visible to keep it out of the way! Keyboard to chatbox: Type to the VRChat chatbox with the OVR Toolkit keyboard. Voice Input to chatbox: Use the free voice input in OVR Toolkit to type into the chatbox. Supports 'Constant transcribe' which will keep voice input active even with the OVR Toolkit keyboard turned off. (Helpful for others who are hard-of-hearing!) Play media in loading screens: OVR Toolkit can automatically play your media when you're in a VRChat loading screen, then pause again after the loading screen ends. (Will continue to play if you started the media before the loading screen) (Find these features in Settings > Customise) Customization Customize keyboard layouts! All keyboard layouts are community made within Unity and documentation is provided so you can do this yourself. (Want the keys to spell out funny things like you're in high school again? Now you can!) Custom Apps allow web developers to integrate web apps into OVR Toolkit, allowing for integrated Twitch chat and games to be made. Module plugins allow .NET/C# developers to directly integrate with OVR Toolkit and display content as a 'module' on the wristwatch. Simulator Mode - Controller-free mode 'Simulator Mode' is a controller-free mode available in OVR Toolkit. In this mode, you can interact with windows using head gaze, and use keyboard binds to move windows around you and change their settings. This mode is perfect for those intending to use OVR Toolkit at a desk or whilst in a sim racing/driving/piloting game! (This mode is still a work in progress, provide feedback in the OVR Toolkit Discord!) Move windows with keyboard binds when you have no controllers connected. Control your cursor position with your head using head-gaze input. Pin windows around you in your play space to view whilst in games. (Race overlays, etc.) Quickly toggle open windows with the 'Edit Mode' bind to show/hide some applications such as Discord, web browsers, etc. whilst in games. 'Voice Attack' ready. (All controls are easily repeatable with the same keyboard key presses to support Voice Attack) Bindable voice input key using Google Speech to type out a sentence into a text box you have selected. Important stuff you should know about We've tried our best to make OVR Toolkit support everything, but that just isn't how this world works! Please read these compatibility notes in mind before purchasing: OVR Toolkit works best when launched as admin, without this, some applications cannot be captured or interacted with. You need to be logged in to the admin account on your PC to run OVR Toolkit as admin. If you don't have the admin account you can still sue OVR Toolkit without admin of course! OVR Toolkit only supports Windows 10 and 11, but simply works better with Windows 11 due to Microsoft updating many of the APIs we make use of to remove bugs in them. Be sure to launch OVR Toolkit through Steam, not other game launchers. You can set OVR Toolkit to auto-start with SteamVR by referring to our wiki! Meta/Oculus users, refer to the OVR Toolkit wiki 'Oculus' page for how to make OVR Toolkit appear in your games if they don't automatically run through SteamVR. (OpenVR) We cannot display our application over Oculus/Meta SDK games or OpenXR games not using the SteamVR OpenXR runtime. (Our application uses SteamVR/OpenVR to display, no one but Steam provides a way for us to display overlays right now!) If you have any issues with the application or find other compatibility issues, don't hesitate to contact us! We'll whip up a hotfix ASAP!
