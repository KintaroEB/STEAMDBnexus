About this gameFull description from Steam+
Dino Dawn is a platformer game about adventure of the Dinosaur in which it needs to rescue eggs. Evil enemies have stolen all his eggs and now the continuation of the genus under threat. Now he needs to save all the eggs and assistant him in this difficult journey will be....pepper!!!! Red pepper, meal which, the hero will be able to spew fire! Defeat enemies with the help of red pepper. Collect eggs to go to the next level. Move around the world map to select the desired level. Listen to wonderful chiptune music.
