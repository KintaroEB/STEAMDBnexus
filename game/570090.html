About this gameFull description from Steam+
Please note: articy:draft 3 is no longer the latest version of articy:draft, therefore active development has ceased. It will only be supported with critical bug fixes but it will not receive new feature updates. This also extends to the articy:draft 3 Importers for Unity and Unreal. Latest supported versions for the articy:draft 3 Importers are for Unity from 2021 up to 6000 and for Unreal UE 5.3 - 5.5. Updates for newer engine versions will not be released. For access to the latest features and ongoing support, check out articy:draft X on , the Articy official website. Articy:draft is a visual tool for creating interactive stories and managing narrative content: witty dialogue, compelling choices, charming characters, useful items, challenging quests, strategic locations, global variables and more. All content can be exported into various formats - including JSON, XML and Microsoft Office. You can also integrate your content easily into Unity or Unreal with the comprehensive articy:draft Importers. Features Plan and keep an overview of non-linear stories Write branching conversations Control game logic with variables and conditions Simulate your story content to find problems early on Manage large amounts of game objects (characters, items, ...) Sketch locations and communicate level ideas Document your game in detail Export to Word Export & Import to Excel for localization Export to JSON or XML to integrate your content Integrate your content in Unity and Unreal easily Commercial Usage and more… Story, Mission & Quest Design articy:draft makes the creation of interactive, branching content easy. It’s perfect for your narrative structure design. Each node in your story or mission flowchart can contain an inner flowchart. You can start with a top-level chapter-like structure and break it down into further and further until reaching single lines of dialogue. This nested approach ensures clean and organized flowcharts. Create variables, conditions and instructions to control the flow your game and make your player's choices count. Use the simulation mode to go through your story from a player's perspective and test your flow logic before you export it. Unity and Unreal Integrations Boost your iteration process. The comprehensive engine plugins get your content ready to use with Unity or Unreal with just a few clicks. Game Object Database articy:draft includes a powerful game object database with a flexible template system. Build everything, from characters, items, spells to weapons and skills. Templates are editable and very iteration-friendly due to their modular setup. Objects inherit the characteristics of their template making it easy to modify or expand them later. Use And Create Plugins Automate tasks and customize workflows by using custom plugins. The Macro Devkit enables you to develop your own plugins fast and easy. Location Planning With the build-in location editor, a vector-based 2D drawing tool, you can easily plan your game world and single levels. This editor is an iteration-friendly sketching tool for maps and scenarios. You can place story events, spawn points and trigger zones on the map for planning purposes. For some game genres, the location editor can even produce the actual game output. For example 2D layer-based backgrounds for point’n’click adventures or hidden object games.
