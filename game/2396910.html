About this gameFull description from Steam+
三國題材的長青樹，獨立開發遊戲的先行者，《吞食天地2：誕生Reborn》將在STEAM平台再次掀起一陣三國MMORPG新旋風！親身體驗吞食天地的各種魅力，現在馬上就加入！ 故事背景 　　東漢末年，盜賊四起，群雄割據。在這個動盪不安的亂世中，來自四面八方的勢力或互相征伐或吞併，隱然形成三大勢力鼎足而立的局面……。而你，這名初入軍營的新兵，是否能破繭而出，成為這個時代的明日之星？現在就開始闖蕩江湖，與各路三國豪傑結交，親身參與歷史上的名戰役，成為新一代的三國英雄吧！ 遊戲特色 多元劇情，暢遊三國！ ．重塑主線劇情：重新演繹三國史詩，共同體驗英雄們風姿颯爽的精采故事。 ．多樣小品任務：融合民間軼聞、原創故事，更結合時事，讓任務更貼近玩家生活。 ．精彩副本任務：副本更有千變萬化的呈現方式，讓你刷得痛快、更刷得樂趣無窮！ 可愛俏皮，奇趣美學！ ．俏皮角色：2.5頭身可愛設計，與之對話還能見到出人意表的角色大頭圖！ ．驚奇武將：經典、神話、東西方各式武將亂入吞食天地2，華麗現身！ ．拉風坐騎：精緻帥氣的拉風坐騎，悠遊吞食世界少不了他們！ ．名勝絕景：三國經典場景融合奇幻風格，建構出獨樹一格的精緻世界觀！ 四大職業　臥虎藏龍！ ．RPG經典職業易上手：一介草民建立功業趁現在！經典RPG職業概念，猛將、豪傑、鬼謀、醫者，職業方向清晰明快，成為英雄就是這麼簡單！ ．配點展現個人特色：除了職業選擇，玩家還能使用點數配點機制，打造極具個人風格的獨特角色，成為不一樣的英雄，在吞食世界大顯身手！ 職業絕技　轉瞬殲敵！ ．職業技能樹：四大職業特技繁多，玩家可依循各職業技能樹，挑選發展方向，練就一身精湛武藝，正是你行走江湖的最佳後盾！ ．技能類別：職業技能各自分為「攻擊技」、「輔助技」、「被動技」，想要精進攻擊/輔助技巧，還是深耕技能基礎，高自由度的特技搭配，由你來抉擇！ 網羅既出，猛將如雲！ ．網羅系統回歸：透過原創「網羅」系統，輕鬆將想要的英雄武將一一納入麾下吧！ ．隨機能力與技能：即使網羅到同一名武將，武將的能力與技能都將不同，多刷幾隻拼出最高能力，讓網羅武將、培養武將充滿樂趣與驚喜！ 神兵利器，戰力爆棚！ ．打造神兵利器：藉由強化、煉化等衝裝系統快速提升戰力，神兵在手不是夢！ ．外顯光芒變化：裝備強化至不同階段，將有不同光芒變化，讓你的強大隨時可見！ 造型混搭，才是流行！ ．豐富武器裝備：玩家身上可穿戴的武器裝備欄位超過10種，徹底滿足你的收集慾望！ ．拉風時裝系統：時裝樣式風格多元，想換就換，任意穿搭，你的造型你來決定！ 輕鬆互動，夥伴同行！ ．吞食展望會：力助新手熬過遊戲初期的艱辛時期，再造輝煌旅程！ ．交友系統：友好度設計能讓你由淺入深與人交心，甚至結為拜把兄弟！ ．師徒系統：有了師父的提攜，徒兒也能安心成長，拉拔後輩成就功德！ ．結婚系統：兩情相悅時，雙雙結婚去！讓你體驗人生大事，情感羈絆更緊密！ ．軍團系統：與成員們共同建設的龐大勢力，也是玩家們安身立命之處！ 放置幫手，最佳良伴！ ．任務小幫手：任務日誌、任務導航、任務追蹤等實用功能，讓解任務成為樂事！ ．魯班盒系統：練功打怪就靠它，輕鬆設定各種狀態下的掛網方式，可說是放置遊戲開路先鋒，無痛掛網最佳良伴！
