About this gameFull description from Steam+
Fortify is a base designer for Rust. Featuring the same parts, placement rules and conditional roof shapes but with extra tools to plan your base faster. Loads almost instantly with low memory usage, can easily run while in Rust to use as a reference when building the real deal. Get the resource count needed to build your base and upkeep required. See a visual for the tool cupboard building and stack block area. See accurate stability numbers while building and test durability in raid mode with explosives. See ranges for auto turrets, shotgun traps, bag timer, heaters and more. Fortify supports the save format used by the Copy-Paste plugin that allows transferring designs into or out of a modded Rust server. Browse and import designs from the steam workshop or publish your own. Join up to 3 other friends in multiplayer mode to build or share a design. Share a design quickly with clipboard export, allows pasting data in a message or a site like to create a shareable link. Fortify has been updated consistently since 2016 to match changes in ever-evolving Rust with more new features still planned. More Features: - different scenes to build in: flat terrain, island, caves and icebergs - symmetry mode duplicates placed parts around a set center with any changes affecting symmetrical parts - automatically include related deployables to frames, doorways and windows - info spots - creates a clickable icon that allows saving a note with the current POV - plan in stages with corresponding colored materials for parts - lots of helpful selection tools including drag select - copy/move selections or snap/align separate selections together - quickly build up with a copy level tool or honeycombing/walling off of selections - practice minicopter flying - merge saves together
