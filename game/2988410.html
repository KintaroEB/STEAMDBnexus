About this gameFull description from Steam+
A simple, friendly front-end for Windows' built-in file compression! SNUG is a management layer for NTFS compression — the lossless, transparent compression already built into Windows. Instead of digging through file properties or memorizing compact.exe commands, you get a clean interface to compress folders, apps, and games with a click. Built on NTFS compression: SNUG doesn't invent its own compression format. It drives the native Windows compression engine — the same technology behind compact.exe — so your files stay fully supported and there's nothing proprietary locking you in. Transparent and lossless: Compressed files work exactly as before — open, edit, and save them like any other file. Windows decompresses them on the fly while SNUG works in the background. Real savings on the right files: Compression works best on text, code, documents, and game assets. Already-compressed files like most videos, JPEGs, and MP3s won't shrink much, and SNUG is upfront about what's actually worth compressing. Light on resources: Because Windows handles the actual work, SNUG stays out of the way with minimal CPU and RAM usage. Set it and forget it: Choose the folders you want compressed and SNUG handles the rest, automatically compressing new files as they're added. Auto-import apps, games, and software: SNUG can detect and import installed applications, games, and software for easy compression. One-click compression for project files: Quickly find and compress project folders for software like Photoshop, Blender, Unity, and more. No file modification: Files are reduced on disk without changing their contents, so they stay fully compatible with their original applications. If your drive is filling up with games and loose files, SNUG makes Windows' own compression genuinely easy to use — no command line, no guesswork. Reclaim disk space with a tool that's honest about how it works.
